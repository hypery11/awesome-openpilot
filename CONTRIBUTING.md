# Contributing

Thanks for helping improve Awesome openpilot. This list covers openpilot, its forks, comma hardware, car ports, CAN/DBC tooling, data and model tooling, and docs.

## Quickest way: open an issue

Use the [Suggest a project](https://github.com/hypery11/awesome-openpilot/issues/new?template=suggest-project.yml) form. Give the link, the category and why it fits. The maintainer adds it to both language versions.

## Opening a pull request

1. Add the entry to **both** `README.md` (English) and `README.zh-TW.md` (Traditional Chinese, Taiwan wording), in the same section and the same position. If you can't write the Chinese line, leave the English text in `README.zh-TW.md` and say so in the PR; the maintainer will translate it.
2. Use this format, one line per entry, ending with a period:

   ```markdown
   - **[Name](https://github.com/owner/repo)** — One-line description.
   ```

3. Link straight to the project (the repository for open-source projects), not to a fork, a mirror or a blog post about it.
4. Write a plain, factual description. No marketing words, no emoji, and no star counts.
5. Check the project is not already listed (search both README files).

## What gets listed

- On-topic and useful to people working with openpilot.
- Open source with a recognisable license, unless it is clearly marked as a reference link.
- Working: it builds or runs, or it is documentation that is still accurate.
- Not archived. Archived or deleted repositories are flagged by a weekly check and then removed or moved to a note.

If you maintain the project, say so in the PR or issue. Self-submissions are welcome.

## Housekeeping

- A weekly link check (lychee) and a weekly archived-repository scan run in GitHub Actions. They open an issue rather than deleting anything.
- The list is CC0-1.0: by contributing you agree to release your contribution under it.

## 繁體中文說明

歡迎推薦專案！最簡單的方式是用 [推薦專案表單](https://github.com/hypery11/awesome-openpilot/issues/new?template=suggest-project.yml) 開 issue，附上連結、分類和推薦理由，維護者會同時更新英文版與中文版。

如果要直接發 PR，請同時修改 `README.md`（英文）和 `README.zh-TW.md`（繁體中文、台灣用語），放在同一個章節、同一個位置，每條一行，描述要客觀、不放星數。不會寫中文也沒關係，在 PR 裡說明即可，維護者會補翻譯。已封存或失效的 repo 會由每週檢查標出來。
